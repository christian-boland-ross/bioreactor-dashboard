# Bioreactor Dashboard

A web-based dashboard for monitoring and controlling a bioreactor.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Recharts

## Development

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```
